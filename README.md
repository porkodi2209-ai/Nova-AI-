## Nova AI

A simple AI chatbot application built using Python, Streamlit, and Hugging Face Inference API.

## Project Description

This project is a web-based chatbot that allows users to interact with an AI language model through a simple chat interface.

The application is developed using Streamlit for the user interface and Hugging Face Inference API for generating AI responses.

Users can enter their Hugging Face API token in the application and start chatting with the AI model.

## Technologies Used

- Python
- Streamlit
- Hugging Face Hub
- Hugging Face Inference API
- Qwen/Qwen2.5-7B-Instruct

## Features

- Simple ChatGPT-style chat interface
- Hugging Face API integration
- Secure API token input using a password field
- Chat history during the current session
- AI-generated responses
- Clear chat option
- Loading indicator while generating responses
- Error handling for API problems
